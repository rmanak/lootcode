# Two worked examples (problem "Meeting Rooms Required": given half-open
# meeting intervals [start, end), return the minimum number of rooms)

## Example 1 — a correct solution
```python
import heapq

def minMeetingRooms(intervals):
    intervals.sort(key=lambda x: x[0])
    heap = []
    max_rooms = 0
    for start, end in intervals:
        # print(heap)
        if heap and heap[0] <= start:
            heapq.heappop(heap)
        heapq.heappush(heap, end)
        max_rooms = max(max_rooms, len(heap))
        # print(max_rooms)
    return max_rooms
```
